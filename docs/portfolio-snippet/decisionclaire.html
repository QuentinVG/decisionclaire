DécisionClaire

Application Laravel d’outils gratuits pour clarifier les décisions d’argent du quotidien : achat raisonnable, reste à vivre, objectif épargne, abonnements et scénarios.

Projet fullstack sans connexion bancaire ni compte obligatoire, avec verdicts prudents, calculs transparents, sauvegarde, export PDF et vitrine GitHub Pages.

  • Laravel 13, PHP 8.3+, Blade, Tailwind CSS, Alpine.js
  • Laravel Breeze, DomPDF, PHPUnit, Pint, Larastan
  • Docker, GitHub Actions, GitHub Pages statique
