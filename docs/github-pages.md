# GitHub Pages

GitHub Pages est configuré comme vitrine statique via `.github/workflows/pages.yml`.

Le dossier publié est :

```text
docs/
```

Cette vitrine présente DécisionClaire, son slogan, sa stack, ses fonctionnalités et les commandes de lancement local.

Limite importante : l’application Laravel complète ne peut pas tourner sur GitHub Pages, car elle nécessite un backend PHP.
